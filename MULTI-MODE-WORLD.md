# Multi-Mode World Doc

**Version:** 0.1
**Status:** Draft
**Scope:** Shared world state across Player, Manager, Agent, Club Owner modes

---

## 1. Core Principle

One world. One timeline. All four modes run inside the same simulated universe.
A decision in Agent mode affects the transfer market that Manager mode sees.
A player jailed in Player mode disappears from Agent mode's client list.

---

## 2. World State

Single shared state object. All modes read and write to it.

```
WorldState {
    current_date        : Date
    season              : int
    leagues[]           : League
    clubs[]             : Club
    players[]           : Player
    agents[]            : Agent
    owners[]            : Owner
    transfers[]         : Transfer (active + history)
    legal_cases[]       : LegalCase (active + history)
    media_feed[]        : MediaItem
    financial_market    : FinancialMarket
    ego                 : EgoState   // the player's current mode + character
}
```

`ego` = the character currently being played. Switches on retirement/death/choice.

---

## 3. EgoState & Mode Switching

```
EgoState {
    mode        : "player" | "manager" | "agent" | "owner"
    character_id: int          // FK to players[] / agents[] / owners[]
    age         : int
    alive       : bool
    legacy_score: int
    children[]  : Character    // available for legacy continuation
}
```

### Switch triggers

| Trigger               | Available modes to switch to                      |
| --------------------- | ------------------------------------------------- |
| Player retires        | Manager, Agent, Owner, or Child (if child exists) |
| Player dies           | Child (if exists), or new career in any mode      |
| Manager fired/resigns | Player (if still active), Agent, Owner            |
| Agent retires         | Manager, Owner                                    |
| Owner sells all clubs | Manager, Agent, Player (if young enough)          |

### Rules

- World time **does not pause** during switch — season continues
- Previous ego character becomes NPC, runs on AI
- Child ego starts at age 15, inherits `legacy_score` bonus to starting attributes
- Can only switch at natural endpoints — not mid-season (except death)

## 4. Shared Systems (all modes read/write)

### 4.1 Transfer Market

All four modes interact with the same transfer market:

| Mode    | Can do                                                  |
| ------- | ------------------------------------------------------- |
| Player  | Receive offers, request transfer, sign contract         |
| Manager | Make bids, negotiate fees, loan players                 |
| Agent   | Propose clients to clubs, negotiate on behalf of player |
| Owner   | Set transfer budget, approve/veto bids                  |

**Conflict resolution:** If two modes controlled by same player try to affect the same transfer — not possible by design (ego = one character at a time).

**AI agents** operate every transfer window — they bid, negotiate, poach clients. Player-controlled agent competes with them.

### 4.2 Reputation System

Global reputation per entity type. Visible to all modes.

```
reputation {
    player_id / agent_id / club_id / owner_id : int
    value       : 0–100
    tier        : "unknown" | "local" | "regional" | "national" | "continental" | "world"
}
```

Reputation affects:

- Which clubs are willing to sign/negotiate (player/manager)
- Which players are willing to sign with an agent
- Sponsor deals available
- Legal case media exposure growth rate
- Election outcomes (owner mode)

### 4.3 Media Feed

Shared news feed. All modes contribute events to it.

```
MediaItem {
    date        : Date
    category    : "transfer" | "result" | "legal" | "scandal" | "retirement" | "award" | ...
    subject_ids : int[]    // player, club, agent, owner involved
    headline    : string
    body        : string
    exposure    : 0–100
}
```

Media items generated by:

- Match results (auto)
- Transfer completions (auto)
- Legal case openings/resolutions (auto)
- Random events with `ton = "elestiri"` or `"mizah"` (event system)
- Agent media collusion (manual, Agent mode)

### 4.4 Financial Market

Shared across Agent + Owner modes:

- Club valuations (Owner can buy/sell)
- Player market values (Agent negotiates from these)
- Bank loan availability (per entity, credit score tracks history)
- Sponsorship pool (clubs + players compete for same sponsors)

## 5. Cross-Mode Events

Events in one mode that affect another mode's world state.

| Event source                 | Cross-mode effect                                                              |
| ---------------------------- | ------------------------------------------------------------------------------ |
| Player gets injured          | Agent's client list shows injury flag; Manager sees player unavailable         |
| Player goes to prison        | Agent loses client (contract void); Manager must replace player                |
| Agent spreads transfer rumor | Player's `on_transfer_list` flag temporarily raised; clubs make inquiries      |
| Club goes bankrupt (Owner)   | All players become free agents; Manager loses job; Agent clients scramble      |
| Manager gets sacked          | Club reputation hit; players' morale drops; affects agent negotiation leverage |
| Owner sells club             | Manager tenure ends; new owner may fire manager                                |
| Player wins award            | Agent reputation +5; club reputation +3                                        |
| Agent convicted of fraud     | All agent's clients get `free_agent = true`                                    |
| Club wins continental title  | Owner reputation +10; all club players' value +15%                             |

## 6. AI Behavior (non-player modes)

When player is not in a mode, that mode runs on AI. AI follows simple rules:

### AI Manager

- Uses current squad, picks best available 11
- Transfers: bids on players within budget, sells players on transfer list
- Does not trigger legal events (AI is clean)

### AI Agent

- Scouts randomly from lower leagues
- Proposes clients to clubs every transfer window
- Does not do media collusion

### AI Owner

- Maintains club budget at break-even
- Does not take bank loans unless club_morale < 30
- Does not buy/sell clubs

### AI Player (retired ego as NPC)

- Plays out remaining career normally
- Can appear in media feed (award, retirement, death)
- Does not interact with player-controlled entities unless event fires

## 7. Legacy Score

Accumulated across all egos (player → child → grandchild...).

```
legacy_score += match_played * 0.1
             + goal_scored * 2
             + trophy_won * 50
             + award_won * 30
             + net_worth_peak / 1_000_000
             - prison_days * 0.5
             - reputation_scandal_hits * 10
```

Legacy score visible in career summary. Child ego gets attribute bonus:

```
starting_ca_bonus = min(10, floor(legacy_score / 100))
```
